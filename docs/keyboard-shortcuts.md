# Keyboard shortcuts

wh_notes uses familiar system shortcuts. On macOS use <kbd>⌘</kbd>; on Windows and Linux use <kbd>Ctrl</kbd>.

## Application

| Action | macOS | Windows / Linux |
| ------ | ----- | --------------- |
| New note | <kbd>⌘</kbd> <kbd>N</kbd> | <kbd>Ctrl</kbd> <kbd>N</kbd> |
| Command palette / search notes | <kbd>⌘</kbd> <kbd>K</kbd> | <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Save now | <kbd>⌘</kbd> <kbd>S</kbd> | <kbd>Ctrl</kbd> <kbd>S</kbd> |
| Export current note | <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>E</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>E</kbd> |

## Editor

| Action | macOS | Windows / Linux |
| ------ | ----- | --------------- |
| Bold | <kbd>⌘</kbd> <kbd>B</kbd> | <kbd>Ctrl</kbd> <kbd>B</kbd> |
| Italic | <kbd>⌘</kbd> <kbd>I</kbd> | <kbd>Ctrl</kbd> <kbd>I</kbd> |
| Undo | <kbd>⌘</kbd> <kbd>Z</kbd> | <kbd>Ctrl</kbd> <kbd>Z</kbd> |
| Redo | <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> | <kbd>Ctrl</kbd> <kbd>Y</kbd> or <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> |
| Toggle checklist | <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>9</kbd> | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>9</kbd> |
| New checklist item | <kbd>Enter</kbd> | <kbd>Enter</kbd> |
| Indent / outdent checklist item | <kbd>Tab</kbd> / <kbd>Shift</kbd> <kbd>Tab</kbd> | <kbd>Tab</kbd> / <kbd>Shift</kbd> <kbd>Tab</kbd> |
| Cut / copy / paste / select all | Standard system shortcuts | Standard system shortcuts |

The sidebar deliberately has no keyboard accelerator, so <kbd>⌘/Ctrl</kbd> + <kbd>B</kbd> always formats selected editor text as bold.
